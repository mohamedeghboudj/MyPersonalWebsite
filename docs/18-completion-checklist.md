# Remaining work before completion

This checklist tracks unfinished implementation and unproven launch gates against briefs `01`–`05`. Completed foundations, console CRUD, static page templates, public CV assembly and the original Sprint 0 proof do not need to be rebuilt. A passing local or synthetic test does not close a live integration or real-device gate.

- [ ] **Finish Phase 3 publishing.** Candidate discovery, private-preview controls and private build reports are implemented in `19`/`20`; complete the production publish path/action with the same ordering guarantees. Prove actual credentials, independent preview Access/MFA, private reports, scheduled capture/report retention and complete save → build → preview/publish → verified pages/PDFs. Measure latency, failures and competing builds on the final path. Retain the last successful release on failure.
- [ ] **Finalize content and presentation.** Populate/review the owner's real profile, timeline, projects/case studies, achievements, certificates, initiatives, skills, languages, links, public contact details and CV selections through the console. Finish EN/FR/AR copy, alt text and interface/SEO copy; replace synthetic media with approved final imagery (using Higgsfield where useful). Review every major section against the references, including typography, spacing, responsiveness and Arabic direction. Verify all content remains editable, category redirects work and certificate originals stay private. Confirm private media downloads; finish orphan-media reconciliation where needed.
- [ ] **Complete Phase 4 contact.** Add the localized accessible form and all submission states, consent/privacy copy, console inbox/message view, prefilled Reply action and mark-replied control. Integrate the existing hardened endpoint and replace the Sprint 0 Turnstile keys with a real widget. Reprove duplicate/rate/abuse handling, notification Inbox delivery and Reply-To, inbox-only writes and scheduled retention on the final deployment. Resolve the privacy obligations identified in brief `05` before collecting real messages.
- [ ] **Complete Phase 5 private CV generation.** Connect the five editable presets, ordered selections and locale/company/role prompt to authenticated compile/download controls, private diagnostics and the payload/template hash cache. Confirm every preset in EN/FR/AR, including mixed-direction text, correct factual content, final owner-content pagination and cache invalidation. Reprove that every public publish includes current trilingual public PDFs without a company prompt or public compile endpoint.
- [ ] **Complete Phase 6 motion.** Build the hero, chronological timeline and project interactions on final content, with restrained supporting sections and one hero-level 3D treatment. Preserve native scroll, animate transform/opacity only, load heavy assets late, and provide designed reduced-motion/low-power alternatives. Recheck the approved references and Arabic layouts after each section.
- [ ] **Close quality gates.** Add/enforce the remaining performance budgets in CI; complete the required publishing, all-variant CV, contact and translation-fallback end-to-end flows. Run axe on every template and check keyboard/focus/contrast. Verify final SEO, redirects, metadata, sitemap, headers and static-only public delivery. Test current Chrome, Firefox and Safari plus a real iPhone and mid-range Android, including RTL/reduced motion and LCP <2.5s, INP <200ms, CLS <0.1.
- [ ] **Complete Phase 7 security and recovery.** Perform the ASVS/security review; close all five-brief acceptance checks, including compiler isolation/injection tests, private origins, Access coverage and minimal bindings/secrets. Set up nightly content-only backup to a private repository, excluding inbox data, and actually restore it. Verify credential rotation, repository protections/secret scanning/dependency updates, owner account keys/passkeys, applicable edge protections and the Cloudflare budget alert without introducing paid dependencies.
- [ ] **Launch and hand over.** Review and merge the stacked PRs after their checks pass; configure isolated production resources/bindings/Access/secrets and migrate approved content. Connect the existing Namecheap/Cloudflare domain when the final public build is ready, verify HTTPS and production contact/CV/publish flows, then retire obsolete spike resources safely. Finish the under-15-minute local setup README, publishing/CV/recovery/backup instructions and final owner acceptance.

The owner's original instructions reserve interactive login, account/security configuration and domain changes to the owner. Implementation and read-only/local verification continue independently; no secret values belong in chat. Writing/article UI and Resend-based in-console sending are explicitly later extensions in the briefs, not requirements for this v1 completion checklist.
